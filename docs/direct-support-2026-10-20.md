# Direct website support

- Replaces the mail-app draft with POST /api/support. Required name, email, phone, topic and message; optional order number and up to three JPG/PNG/WebP/PDF attachments, 2 MiB combined. Get help in Order Status links here and prefills the order reference.
- Uses existing server-only Gmail SMTP settings. Recipient fixed to configured ADMIN_ORDER_EMAIL, sender remains the verified store address, reply-to is the validated customer address. No arbitrary-recipient email, customer autoresponder or public upload URLs. No additional credentials needed.
- Request body is stream-bounded to 2 MiB plus 64 KiB multipart overhead before parsing, independently of Content-Length. Server validates contact fields, file count/aggregate size, extension, MIME and magic bytes. Files use generated safe names and in-memory buffers, not filesystem/URL attachments. These checks are not an antivirus service: customer files remain untrusted and the email explicitly warns the operator. No permanent upload storage added.
- Existing private database-backed request guard limits each hashed source IP to three attempts per 15 minutes, rejects cross-origin submissions and fails closed if unavailable. Hidden honeypot adds a low-cost spam check. This is not a CAPTCHA or a guarantee against distributed spam.
- Browser prevents concurrent submissions, freezes fields while sending, retains details/files on errors and clears them only after SMTP acceptance. A support reference is shown on success and included in the owner's branded email. SMTP acceptance is not proof of inbox placement. There is no persistent dashboard ticket queue, automatic retry or incoming-reply ingestion; staff respond from the support inbox. Ambiguous SMTP errors do not trigger an automatic resend.
- Isolated tests cover multipart body limits, malformed contacts, filename/MIME/signature checks, count and size limits, recipient restriction, reply-to, SMTP failure, honeypot and guard. Existing email/request-guard tests pass. TypeScript, scoped ESLint and Vercel production build pass.
